💡 Executive Summary

Following the successful restructuring of the 10-step onboarding workflow and role segregation, this plan details the technical resolution for the 6 feedback points highlighted in the 29-Jul feedback document. This includes implementing a multi-select List of Values (LOV) for financing purpose, dynamic post-registration loan onboarding modal, workflow step resumption, working document uploaders, historical yield edit/delete functionality, and fixing the Step 9 supervisor submission handler.

🎯 Detailed Implementation Plan
Item #1 · Farmer Registration Form Planned Fix
"In Financing Purpose field, give dropdown LOVs. Multi LOVs can be selected and removed if selected. Also, unable to upload docs during registration."
Technical Execution Plan:
1. Replace single text input in NewFarmerView.jsx with an interactive Multi-Select LOV dropdown containing predefined purpose options (Crop Seeds & Input, Fertilizers & Pesticides, Solar Tube-well, Land Prep, Implements).
2. Add removable tag chips with ✕ delete buttons for easy tag management.
3. Enable active drag-and-drop file upload handlers for CNIC Front/Back & supporting documents during initial registration.
Item #2 · Onboarding Modal & Sidebar Navigation Planned Fix
"Once farmer is registered, pop up should be shown if you want to onboard Farmer now for loan or not. Then that 10-step workflow will open. Rename it to 'Farmer KYC Onboarding'."
Technical Execution Plan:
1. Add post-registration modal prompt: "Farmer Registered Successfully! Would you like to start Loan Onboarding for this farmer now?" with direct action buttons (Start Loan Onboarding Now vs Go to Applications Queue).
2. Rename sidebar navigation menu item from '10-Step Workflow' to 'Farmer KYC Onboarding' in App.jsx.
Item #3 · Document Uploads on Steps 2 & 3 Planned Fix
"Unable to upload docs on step 2 (KYC) and step 3 (Land Verification)."
Technical Execution Plan:
1. Attach working file inputs & state handlers for eCIB report upload on Step 2 (KYC).
2. Attach working file inputs & state handlers for Fard / Land Registry document upload on Step 3 (Land Verification).
3. Show green uploaded badge feedback once files are selected.
Item #4 · Workflow Resumption & State Persistence Planned Fix
"I left the onboarding and closed. When I opened it from Applications it opened from Step 2. However it should open from where I left (step)."
Technical Execution Plan:
1. Update WorkflowView.jsx initial state logic to resolve the saved application status and automatically set currentStep to the farmer's saved progress step.
2. Store active step context so reopening any application from the queue resumes seamlessly at the exact step left off.
Item #5 · Historical Yields Edit & Delete (Step 5) Planned Fix
"When historical yield is added, option to delete and edit should be given."
Technical Execution Plan:
1. Add Edit (✏️) and Delete (🗑️) buttons on every historical yield card in Step 5.
2. Implement backend routes PUT /api/applications/:id/historical-yield/:yieldId and DELETE /api/applications/:id/historical-yield/:yieldId in applications.js.
3. Connect edit modal to update yield maunds & harvest dates dynamically.
Item #6 · Step 9 Transition Submission Handler Planned Fix
"After submission from Step 9, it shows error 'Could not process workflow update. Please try again'."
Technical Execution Plan:
1. Update Step 9 transition logic in applications.js and WorkflowView.jsx to handle financing requirement selection cleanly.
2. Ensure status transitions to Pending Approval without throwing alert errors and displays officer completion modal.
